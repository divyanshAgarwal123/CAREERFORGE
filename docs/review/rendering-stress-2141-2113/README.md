# Rendering workload acceptance: robotics and genomics

Exact source heads, actual parent, branches and issue IDs are recorded in source.json. Both issues were audited against current main, full comments/timeline references, all open PRs and current contribution rules. Actual bot assignments were confirmed before branch creation or coding. Existing benchmark-suite pages time CPU operations; their generated-series visualizers and interaction analytics do not implement the requested animation-frame jitter/DOM-work lab. These changes add only the four required isolated telemetry-stress-tester files per showcase and preserve common files.

The modules measure actual requestAnimationFrame intervals while updating 64 real DOM nodes and forcing a layout read. Jitter is independently computed from adjacent interval differences. A bounded documented workload index combines measured FPS/jitter/layout cost. Optional approximate Chromium JS heap readings may decrease during garbage collection and never enter the score. Forced layout is a rendering proxy, not direct GPU paint timing. All data stays in the page.

Ten focused Node cases per module, scoped oxlint and both normal Node22 builds pass.
